# Dashboard UI

Dashboard 使用 React、Next.js 静态导出管线（`output: "export"` → `app/out`）、Tailwind CSS 4 与 shadcn/ui（Radix / New York）。生产态由 `@ludens/core` 的统一 `ludens app-server` 同时直接承载 `/api/*` 与静态前端构建产物，不运行任何 Next.js 服务端进程；前端开发态下 `npm run dev` 自动拉起后台 `ludens app-server` 并代理 `/api/*` 以提供 HMR。浏览器页面与一等 Electron **Ludens 桌面端**（`ludens-app`）共用同一份构建产物，不需要启动 Electron 才能开发 UI。

## 组件归属

- `app/components/ui/` 保存通过官方 shadcn CLI 引入的组件源码。按钮、表单、开关、复选框、单选组、滑块、卡片、表格、对话框、反馈与页内标签应复用这里的原语。
- 业务组件仍放在 `components/`；运行时间轴、活动证据、图表和桌宠动画由业务组件实现，不往 UI 原语里加入工作区或 Ludens 调用。
- 类名合并使用 `import { cn } from "cn"`，变体用 `class-variance-authority`；它们与当前 shadcn 注册表生成的源码保持一致。

`components.json` 记录注册表风格与路径。需要新组件时在 Dashboard 目录运行，例如：

```bash
cd app
npx shadcn@4.23.0 add dialog
```

只添加当前使用的组件。生成后审阅源码与锁文件，不用 `--overwrite` 覆盖本地修改。当前本地调整包括 `NativeSelect.wrapperClassName`（控制包装层宽度）以及 Slider 将可访问性名称与描述传给真正可聚焦的 Thumb。Card 使用适合控制台的紧凑默认值：20px 内边距、16px 区块间距与 13px 说明文字。

## 主题与样式

`app/globals.css` 引入 Tailwind 和 `tw-animate-css`，通过 `@theme inline` 将现有 Ludens 深色配色映射到语义 token。根布局固定使用 `dark`，当前没有新增主题切换功能。

| 用途 | 推荐类名 |
| --- | --- |
| 页面与主文字 | `bg-background text-foreground` |
| 卡片和浮层 | `bg-card` / `bg-popover` |
| 主操作 | Button 默认变体，使用 `primary` 金色 |
| 次操作与弱背景 | Button `secondary` / `outline` / `ghost`；`bg-muted` |
| 说明与状态 | `text-muted-foreground` / `text-success` / `text-destructive` |
| 边框、键盘焦点 | `border-border` / `ring-ring` |

注意 `--muted` 表示弱背景，文字使用 `--muted-foreground`。已有领域 CSS 放在 `@layer components`，允许 Tailwind 的 `utilities` 层覆盖；不要新增未分层的全局 `button` / `input` / `select` 样式，否则会压过共享控件的状态、尺寸和焦点样式。

工作区管理、设置、Capabilities、Docs、活动流、请求详情、回放控件与 Loop Lab 使用共享原语。时间轴刻度、图表、证据行和媒体等领域布局保留在业务 CSS 中，周边表面与状态色使用主题 token。

视觉基线是暖炭灰底色、克制的金色操作、轻边框与统一卡片间距。设置优先展示控制台偏好。桌宠关注区域将已保存工作区与观察到的桌面端状态分开展示。此窗口的可选桌面控制有独立的可用性区域，桌面偏好卡片从 1100px 起使用双列；窄屏使用单列。相关控件放在一起，允许翻译后的标签换行；参考生成图调整界面时，必须用真实中英文页面检查桌面和窄屏排版。

**性能（`?view=perf`）**将顶部栏整合为单一紧凑的 `.perf-toolbar`（左侧为`性能概览`与`请求与调用链回溯`标签页，右侧为实时状态指示器、紧凑版 `RunPicker` 与`交回控制`按钮），不再保留独立的页面大标题。在`请求与调用链回溯`（`perfTab=requests`）标签页下，桌面端视口（`>=1080px`）采用有界的 `100dvh` 双列独立滚动工作台，将独立滚动的请求列表与右侧详情及证据面板并排呈现；窄屏下将请求选择器与详情上下堆叠。汇总 KPI 对 `autonomyActionRatio` 百分比显示做 `100%` 封顶保护，趋势与遥测网格按视口平滑切换 `3 → 2 → 1` 列。缺少测量值时，图表会说明原因而不是只画空坐标轴；记录中的零值、只有等待时长的延迟和数据缺口仍保留各自含义。

在同一工作区路径、运行、周期和分页内切换请求时，请求控件会保持显示，让详情单独加载。详情只属于精确匹配的读取和请求 ID；加载中、失败或找不到的选择不能把上一条请求冒充为新选择。读取失败提供显式重试，重试成功仅在用户尚未移开焦点时恢复焦点；切换工作区、运行、周期或分页不能保留其他范围的内容。

工作区入口采用可搜索的列表，新建、添加已有目录和修改默认位置分别在对话框内完成。目录可用的工作区卡片会展示 `ludens.json` 核心参数摘要（`driver`、`model`、`seconds`/`requests` 预算、`compactionThreshold` 以及开启 `connection.imageUrls.enabled` 时的 `blob-broker` 徽章），并提供**打开**（`?view=live`）、一键**启动工作区**（由 `app/lib/use-workspace-service.ts` 中的统一 `useWorkspaceService` Hook 驱动，调用 `PUT /api/workspaces` `workspaceServiceControl`）与**配置与服务**（`?view=perception`）操作入口；创建或登记完成后的确认横幅同样并排提供**启动并打开**与**打开工作区**。尚未产生运行的空工作区在运行页（`WorkspaceRunEmpty`）也会优先呈现**启动工作区**主操作按钮、内联 `stderr`/`stdout` 诊断横幅、前往**基座**与**配置与服务**的快捷入口，以及可展开的终端命令提示（`ludens --workspace '…' up`）。清除无结果的搜索后，焦点回到持续存在的搜索框，下一次 Tab 可进入恢复的列表。高级字段折叠展示，社区驱动字段由已验证的 manifest 决定，并预览最终位置。写入完成后，即使后续目录刷新失败，也应保留成功状态；使用返回的身份显示确认信息并导航。

在运行页、回放和运行剖析中，显式重试工作区列表时，读取中的按钮保持可聚焦并阻止重复触发。读取失败后仍可在原处重试；成功恢复使按钮消失后，只有原先聚焦的重试操作仍保有焦点意图，焦点才会转到主内容。移开焦点、在其他位置操作指针或改变 URL 都会取消恢复。目录自动轮询不会创建焦点恢复请求，目录恢复与运行数据重试仍各自独立。

默认位置修改返回已提交的 `{ config }`；移除返回 `{ removed }`，包含加锁后实际删除的登记项，原本已不存在则为 `null`。界面先应用这些操作结果，再独立刷新目录；重试读取不会重复写入。撤销使用返回的路径，不使用过期列表行。注销前，CLI 与 Dashboard 共用的操作仅清除指向该工作区的桌宠目标。目标清理失败时保留登记，用户修复问题后可显式重试。成功移除后，重新登记目录不会恢复旧跟随。

控制台采用 `100dvh` 原生三栏工作台外壳（`Sidebar | Primary Stage | Collapsible/Drawer Inspector Dock`），并通过 `--shell-topbar-height`（Electron 桌面端或 `?desktopPreview=darwin|win32` 预览模式下为 `38px`，普通浏览器模式下为 `0px`）精准预留顶栏高度，确保各个主舞台不出现双滚动条或底部截断。在 Electron 桌面端，一体化的 `38px` `#090a0d` 顶栏集成了侧栏折叠（`Cmd/Ctrl+B`）、前进/后退（`Cmd/Ctrl+[` / `]`）、快速跳转（`Cmd/Ctrl+K`）、工作区面包屑、桌宠开关与刷新，配合 macOS 原生红绿灯（`hiddenInset`）或 Windows 11 原生窗口控制叠加层（`titleBarOverlay`，彻底移除传统 Win32 灰底菜单栏），并在 `window-state.json` 中持久化带多屏边界校验的窗口尺寸与位置；点击窗口关闭按钮（`×`）仅隐藏至系统托盘与 **Ludens Pet** 桌宠，而显式退出（`⌘Q` / 托盘 **Quit**）则会关闭受监管的 `ludens app-server` 并干净终止全部受管游戏 AI 子进程。URL 的 `view` 参数同时将 `"capabilities"` 归一化为 `"caps"`、将 `"studio"` 归一化为 `"perception"`。桌面端的工作区与全局导航共用侧栏中间滚动区，左下角 `.sidebar-footer` 将紧凑版 `WorkspacePicker`（`variant="sidebar"`，在全局视图 `workspaces`、`docs` 与 `settings` 下呈柔和弱化态并附带作用域提示）永久锚定在**设置**正上方；`.sidebar-footer` 上的 `ResizeObserver` 确保状态与布局变化时步进 `.nav-cursor` 始终精准对齐**设置**。较矮的窗口不能把导航挤出可达范围，键盘焦点到达链接或操作时相应条目会滚入可见区域。宽度在 `680px` 及以下时，侧栏收起为滑出式抽屉，由各工作台顶栏左侧插槽（或非工作台页面的轻量 `.mobile-shell-bar`）触发；跨越该断点时，仅在当前聚焦的侧栏控件变为隐藏时转移焦点。

工作区选择器打开一个高度受限的弹窗，候选按钮在选择前展示完整名称和目录；目录数据缺失时使用真实工作区 ID。当前选中项和不可用目录有明确标识，不可用条目仍可选择。候选列表单独滚动，标题与关闭按钮保持可见。打开、关闭或选择当前工作区不会改变导航；选择其他工作区时，通过既有范围重置导航提交其精确 ID。目录列表变化会更新候选项，选择器不会自动提交选择；父页面保留既有的上下文回退规则。关闭后焦点回到侧栏左下角触发器。

运行记录使用同样的有界选择面板，并以无外部前缀标签的紧凑版 `RunPicker`（`variant="compact"`）按上下文内聚在真正消费运行状态的三个视图中：**运行（`?view=live`）**（`.codex-thread-header` 右侧操作区）、**回放（`?view=replay`）**（`.replay-studio-topbar-left`）与**性能（`?view=perf`）**（`.perf-toolbar` 右侧簇）。每个已记录候选项在选择前展示完整 ID，只有合法的标准时间戳前缀才附带可读时间。时间摘要包含年份和秒，并明确采用 Asia/Shanghai 时区；自定义或形似时间戳但非法的 ID 保持原样，不会被归一化成日期。独立的“最新运行”入口保留空值行为，与显式选择对应的历史运行不同。精确选中值、目录顺序和原有导航保持不变。在**运行（`?view=live`）**页中，整个工作区呈现为单一连续会话流：向上滚动会自动加载更早的条目并按需拼接先前 `runId`，同时自动补齐较矮视口；顶栏内的 `RunPicker` 作为**快速跳转导航器（Quick-Jump Segment Navigator）**，列出当前与历史控制周期分段（`runId#epoch`）及更早的运行，选择任意条目会在会话流内平滑滚动并高亮对应分段，而不会离开实时视图或锁定底部实时控制台。工作区与运行选择器共用关闭、滚动和焦点行为。

设置在浏览器中即可使用，无需 Electron，并在顶部提供吸顶的分组快速跳转胶囊栏以便在配置分区间快速定位。语言位于最前，关注工作区仍通过服务端提供。浏览器偏好恢复后，桌面桥接会把语言同步到原生菜单、桌宠渲染层和 `companion.json`；首次服务端渲染的英文不会覆盖已保存的桌面语言。**新建工作区全局默认参数（Global Workspace Creation Defaults）**卡片支持编辑 `$LUDENS_HOME/config.json` 的 `defaults`（通过共用的 `ModelPickerDialog` 选择 `model` 及其推理强度 `effort` 与响应速度 `serviceTier`，模型输入框旁以强度徽章及 Standard/Fast/Ultra 速度徽章直观标示，以及 `seconds`、`requests`、`compactionThreshold` 与 `pet`）。模型连接与多模态传输（Model Connection & Multimodal Transport）区域紧随其后，支持在全局默认值（`$LUDENS_HOME/config.json` 的 `defaults.connection`）与单工作区覆盖配置（`<workspace>/ludens.json` 的 `connection`）之间切换并编辑 `openaiWebsockets`、`cacheRetention`、`appendOnlyContext` 与 `imageUrls`（`enabled` 及有序 `backends`），同时内置可展开的三层多模态传输架构指南（对比有状态 WebSocket 增量、无状态 HTTP 前缀 KV 缓存与图床 URL 卸载在长周期视觉循环中的表现差异）以及可复制的工作区 Host 重载命令（`ludens down --keep-emulator && ludens up`）。可选桌面区域只在显式检查及窗口焦点、可见性变化时检查当前窗口的桥接，不会启动桌面应用，也不会把服务端消费端的连接视为本地桥接。可见性、声音和通知在读取前保持未知，不会显示为禁用的默认值。读取失败会保留并标注缓存值，提供只读重试。无法确认结果的写入不会重放；再次修改前需重新读取设置。桥接生命周期、操作标识和更新的订阅值共同保护读取、写入、文件验证与声音预览，防止桥接替换或断开后的迟到结果污染当前状态。

桌宠关注选择器即时保存，保存期间保留焦点。目标 PUT 返回精确提交的 `{ target }`，桌宠心跳 POST 返回 `{ consumer }`，两种回执都不依赖后续读取。界面先应用目标回执，再独立读取桌面端状态。心跳读取失败仍保留目标，并将连接状态标为未知；完整读取失败则保留并标注已保存或缓存的选择。保存响应缺失时保持“尚未确认”，同时显示请求目标与上次确认的目标，在显式读取成功前禁止其他更改。恢复操作不会重复写入。路径与原始错误按需展开。已保存选择、桌面连接与应用状态是不同事实：`targetRevision` 表示正在尝试的选择，`revision` 表示已加载的来源，因此旧错误不会归到新选择。离线或失去登记的目标仍以 `targetUnavailable` 保留展示；桌面端停止消费该来源而不清除选择，恢复可用后可以重新连接。首次保存之前，选择器显示尚未设置。显式选择**停止跟随**会保存 `null`，使后续 `ifUnset` 启动无法自动选择工作区。

**配置与服务（`?view=perception`）**在页眉提供由 `useWorkspaceService` 驱动的快捷控制按钮（未运行时显示**启动工作区**；运行中显示**重载**与**停止**，失败时展示带**基座**跳转入口的可关闭诊断横幅），并通过支持自适应换行的水平页签栏（`h-auto min-h-9`，确保窄视口换行时不挤压文字）将五个工作区维度的页签整合为统一工作台：**模型与预算**（通过共用的 `ModelPickerDialog` 编辑 `<workspace>/ludens.json` 的 `model` 及其推理强度 `effort` 与响应速度 `serviceTier`（模型输入框旁以强度徽章及 Standard/Fast/Ultra 速度徽章直观标示），以及 `seconds`、`requests`、`compactionThreshold`、驱动 `executable`/`gamePath`，并提供一键**立即重载**按钮使新配置对运行中 Host 立即生效）、**连接与多模态传输**（自动锁定当前选中工作区）、**后台服务与会话**（实时探查 `emulator`/`baseware`/`host` 后台服务的运行状态与日志尾部、通过 `useWorkspaceService` 支持一键执行 `up` / `reload` / `down` 生命周期操作及复制对应 CLI 命令、`.ludens/shiori/current-session.json` 活跃会话指针重置与 `.ludens/shiori/sessions/` 历史会话切换，以及内联 `MEMORY.md` 编辑器）、**感知录制参数**与**上下文容量推演**。感知录制页签采用精确数值输入、预设、辅助滑条及明确的覆盖/继承来源。草稿按工作区身份与登记路径隔离，并保留在当前标签页；保存、重新读取与检查运行进程分别操作。只有当前工作区宿主的可靠观测才能提供运行值，不推断继承值来源。可复制的重载命令包含工作区，并清除继承的 socket 覆盖；页面不会执行命令。详见[感知配置与恢复](../tutorials/perception-and-action.md)。

继承规则统一显示在字段上方。每项保留用途与来源选择器，选择继承时显示该项明确标注的内置默认值。这些默认值是回退值，不是运行进程的观测证据。已保存设置与运行观测保持为独立区域，宽屏并排、窄屏堆叠，保留读取与恢复操作。

能力页并列呈现工作区的 **Capability – Eval – Env** 三元拓扑、可折叠的三联可视遥测图表（验证率环形图与三层契约覆盖条、多序列自演化评分轨迹曲线、评测耗时与断言密度分布图，提供**展开/收起评测概览**开关以便让能力声明在紧凑视口首屏即可触达）、一键**运行全部评测**（`ludens eval --all --json`）与单能力**运行评测**（`ludens eval <id> --json`）触发器，以及代理评测环境目录（`@eval_env`）。工作区能力卡片展示三元节点关系（`@capability` → `@eval_capability` → `@eval_env`）、源码位置、短 `codeSHA` 摘要、三向过期归因、带进度条的评分指标、内联评分演化迷你曲线（sparkline）、直达回放的演化录像链接（`?view=replay&replayRecord=...&replaySequence=1`）以及可展开的自演化历史记录。控制器接口目录与受控节点绑定从能力页统一链接至专用的 **基座（`?view=baseware`）** 工作台。

Loop 实验室是本地数学模拟，与工作区设置和实际运行无关。选择交付方案后，展开**调整模拟**编辑参数草稿，再统一应用。空值、非有限数、超范围数值及非整数的计数字段会显示就地错误，之前的估算结果不变。**重置参数**恢复数值默认值，不修改层配置。层开关会立即使用已应用参数重新计算；不匹配任何预设的组合标为**自定义层配置**，不会错误选中旧预设。所有对比方案使用相同的已应用参数，包括单轮方案中的显式 observe。草稿、已应用参数、层配置和请求选择在当前标签页内跨导航、语言切换保留；刷新浏览器会开始新的实验会话。

窄屏默认折叠参数，先展示估算结果和图表。精确请求编号、上一条/下一条按钮、滑条与图表共享同一选择。SVG 图表随宽度变化而保持高度，在受影响请求之前标出压实，并将历史上下文压实阈值与请求总量分开说明。**累计交付帧 token**统计每次成功交付的帧载荷，不含状态通知，也不因压实而减少；**保留的感知 token**包含仍在上下文中的感知文本、图片及状态通知。请求明细展示本次模拟的实际数值。方案比较为每个方案保留一个按钮和带标签的全部六项指标，按比较面板的可用宽度从列排转为卡片。重排时同一个按钮保持键盘焦点，选中状态、已应用参数和估算结果不变。循环结构和最近模拟历史作为次要内容按需展开。实验室中的操作不会启动模型或改变真实运行。

宽度在 900px 及以下时，文档侧栏切换为 **文档目录** 菜单；在 1300px 及以下时，页内侧栏切换为 **本页目录** 菜单。每个侧栏与替代入口共用包含边界值的断点。缩放窗口使当前导航控件隐藏时，焦点会转到对应的可见入口。已打开的目录在缩放时保持打开；关闭后将焦点交还可见的触发按钮或对应侧栏。选择文档或标题仍聚焦阅读位置，缩放不会改变搜索草稿、工作区或语言。

目录弹窗的标题与唯一关闭按钮位于滚动内容区之外。说明、完整文档标题、搜索和目录链接在内容区内滚动，让短窗口中的固定标题栏保持紧凑。键盘导航会把到达的条目滚入可见区域；从末项循环到关闭按钮时，该按钮保持可见，无需滚动整个弹窗。

文档、能力与感知设置在读取失败后提供显式重试。刷新失败仍保留上次内容；驱动验证结果和未保存的感知修改与 GET 状态分开管理。工作区目录读取失败显示错误，不会伪装成空工作区列表。重试读取不会重复写入，感知设置保存成功后的值优先于此前发出的读取。

回放在全宽 `100dvh` 演播室中分别管理播放采样和事件查看，配备严格单行不折行的 `46px` `.replay-studio-topbar`（内聚 `RunPicker`、感知能力筛选器、窄屏自动图标化的次要操作及 `<PanelRight />` 检查器开关）、无高度死锁并保留完整跳转按钮的弹性媒体画布，以及上下分层的 `24px` `.replay-time-axis` 时间标尺（将自适应 `3`/`5` 刻度文字置于上层、橙色 `.replay-playhead-cap` 置于下层以避免重叠）。播放通过统一回放会话（`useReplaySession`）按有界的 30 秒画面窗口（画面 API 每次最多接受 60 秒）与最长达 15 分钟的事件窗口加载数据，结合随倍速扩展的前瞻预取、播放头锁定的多窗口 LRU 驻留、相邻视频分片解码器预热以及解耦的外部播放时钟，在跨越窗口或分片边界及连续拖拽定位时保持流畅且不清空事件轨道。精确已过时间输入、前后十秒跳转与进度条都在所选运行或周期内定位。缺失采样与录像缺口保持可见，不得用较晚画面充当较早时刻的证据。

**跳转时间** 接受秒数、`分:秒` 或 `时:分:秒`，秒数最多可带三位小数。可编辑值保留毫秒，重复提交仍停在同一位置。未编辑的输入框会跟随外部定位更新，包括同一秒内的定位；未提交的编辑保持不变。无效输入不会跳转，超过录像范围的值会限制到末尾。时间轴和搜索结果中的静态标签保持整秒精度。

右侧**事件流／证据详情**检查器栏通过 `46px` 页签栏与 `.replay-studio-topbar` 底边齐平，宽视口（`>=1100px`）支持通过 `<PanelRight />` 自由收起，窄于 `1100px` 时自动切换为右侧滑出浮层抽屉（支持遮罩、关闭按钮或 `Escape` 收起），并将事件检索头部浓缩为紧凑双行（首行为搜索输入框与定位当前时刻，次行为横向滚动轨道胶囊与匹配批次操作）。回放工具栏的 **查找事件** 打开事件标签（若检查器已收起则一并展开抽屉/侧栏）并聚焦搜索框，不执行搜索、不改变播放状态或时间，也不清除查询、结果和证据选择。结果条目在完整事件标题上方集中显示已过时间、类型和状态，长文本自然换行。用户明确切回事件标签后，窗口宽度变化会保留该选择；新选中的证据仍会打开详情，当前处于详情时则按需在内联检查器与抽屉/弹窗之间切换。

回放事件搜索通过服务端现有归档索引读取整个所选运行或周期。搜索按不区分大小写的字面文字匹配标题、状态、事件类型及标识符，可按轨道筛选；不搜索任意载荷，也不展开附件。每次响应最多扫描 500 条候选事件、返回 100 条匹配。界面会自动越过无匹配的扫描页，支持取消与重试，并限制当前展示的结果批次大小。游标将查询及范围绑定到源代次和固定事件快照：追加事件需重新搜索，源文件重写会使旧游标失效。扫描完该快照与完成整个归档的索引是两件事；只有 `scan.complete` 与 `coverage.complete` 同时成立，才能声称结果完整或明确没有匹配。

回放证据链接保留工作区、运行、周期和时间，以及 `replayItem`，或 `replayRecord` 与 `replaySequence`。原生链接支持新标签页和浏览器历史。详情展示已记录的标识符、时间、状态、原文，以及确有记录的模型输入；缺失的输入媒体不会被邻近截图替代。截断文本明确标为节选，完整记录仍可在原始数据折叠区查看。无效或不可用的引用保持明确可见。定位、搜索、复制链接、读取详情与重试读取都不会启动驱动、模型或游戏，也不会改变宿主控制权。

回放证据使用紧凑的 **录制证据** 标题栏，并固定显示 **关闭** 操作。完整标题、录制原文、精确输入和元信息在内容区内滚动，长记录与延迟载入的图片不会把关闭按钮推离视口。来源标识与原始 JSON 默认折叠。切换证据后从内容顶部开始阅读；关闭时保留播放位置，并在可用时将焦点交还打开入口，直接链接则使用导航控件作为回退。

## 交互约定

- 表单控件关联 `Label`，帮助信息通过 `aria-describedby` 关联。图标按钮必须有可访问名称。
- 对话框必须有标题和说明，打开时聚焦第一个有用的输入；取消后返回触发按钮，创建成功后聚焦结果。正在创建时保持进度可见，避免意外关闭。
- 明确按钮的 `type`；原生表单的提交按钮用 `submit`，其他操作用 `button`。
- `NativeSelect` 保留原生选项、空值和键盘行为；离散开关用 `Switch`，数值范围用 `Slider`。
- 请求详情使用共享 `Tabs`，支持方向键、Home 与 End；未激活面板不挂载。
- 整行证据与时间轴点击区域可保留显式类型、可见键盘焦点的原生按钮。回放进度条保留原生 range，维持连续毫秒定位及指针／按键释放时提交 URL 的行为；隐藏的声音文件输入也保留原生实现。
- 有后端写入的滑块用 `onValueChange` 更新本地值，`onValueCommit` 保存，避免拖动过程中连续请求。
- 业务请求、等待态、错误反馈与桌面能力检测由页面维护，UI 原语只负责展示和交互。

验收使用 `npm run typecheck`、`npm test`、`npm run build`，并在隔离的 `LUDENS_HOME` 下检查页面与表单操作。详见[控制台调试与验证](../tutorials/debugging-and-verification.md)。

## 品牌标识

Ludens 标识是一个 5 × 5 像素环，环内留出镂空的 L，右上角有一颗独立像素。像素环使用所在表面的文字颜色；独立像素始终为强调橙色（`#ff4f1f`，`--gold`）。像素保持方正：不加圆角、阴影、描边或旋转。

| 用途 | 文件 |
| --- | --- |
| 深色背景 | `app/public/brand/ludens-mark-dark.svg` |
| 浅色背景 | `app/public/brand/ludens-mark-light.svg` |
| 应用图标底板（桌面窗口与程序坞） | `app/public/brand/ludens-app-icon.svg` · `ludens-app-icon.png` |
| 桌面菜单栏托盘图标（`@1x` `18×18` / `@2x` `36×36`） | `app/public/brand/ludens-tray-dark.png` · `ludens-tray-dark@2x.png` · `app/public/brand/ludens-tray-light.png` · `ludens-tray-light@2x.png`（`app/desktop/tray-icon.ts` 中的 `createLudensTrayIcon`） |
| 浏览器标签页与触控图标 | `app/app/icon.svg` · `app/app/apple-icon.png` |
| 控制台侧栏与应用内使用 | `app/components/ui/pixel-mark.tsx` 中的 `PixelMark` |

Electron 菜单栏 `Tray` 将 `ludens-tray-dark`（`#f3f2ee` 像素环 + `#ff4f1f` 独立像素）或 `ludens-tray-light`（`#171817` 像素环 + `#ff4f1f` 独立像素）加载为整数像素网格的多倍率 `NativeImage`（`scaleFactor: 1` 与 `scaleFactor: 2`，不做 `.resize()` 缩放发虚），并随 `nativeTheme` 变化自动切换深浅色变体。`app/public/companion/ludens/icons/` 下的桌宠蜘蛛资源（`icon-tray.*`）仍专属于 Ludens 桌宠目录。

### 动效

标识的各个部件承载控制台的动效。所有运动都落在像素网格上、按步进行：只有一个时间变量（`--step`，60ms），只使用 `steps()` 缓动，只改变 transform 与 opacity。全局的减少动态效果规则会关闭全部动效。

`PixelMark`（`app/components/ui/pixel-mark.tsx`）负责绘制标识；`app/app/pixel-motion.css` 存放时间变量与关键帧。

| 属性 | 效果 |
| --- | --- |
| `state` | 独立像素作为状态灯：`idle`、`reasoning`（脉动）、`recording`（闪烁）、`passed`（绿色）、`failed`（红色并抖动）、`waiting`（灰色慢闪） |
| `loading` | 三像素的尾迹沿像素环循环 |
| `filled` | 镂空的 L 以蓝色逐格填满：表示由人接管控制 |
| `assemble` | 像素环顺时针落下，独立像素最后落位，仅在挂载时播放一次 |
| `label` | 无障碍名称；未提供时标识仅作装饰 |

静止时像素环是一条完整轮廓，只有设置了 `loading` 或 `assemble` 时才拆成十三个独立格子。鼠标悬停或键盘聚焦侧栏品牌时，独立像素会跳一下。

在控制台外壳中：

- **侧栏光标。** 宽度大于 680px 时，一颗橙色像素标记当前导航链接，并分四步跳到新选中的链接。它的位置由当前链接实测得出，因此滚动和缩放时直接跟随，不播放步进移动。宽度在 680px 及以下时，菜单保留静态下划线。
- **加载指示。** 非刷新操作的等待状态使用 `<PixelMark loading />`，不再使用圆形旋转图标。刷新按钮保留旋转箭头。
- **组装。** 侧栏品牌在每个浏览器会话中组装一次，由会话键 `ludens:brand-assembled` 记录。

在运行页：

- **状态像素。** 状态徽标用 `PixelMark` 取代圆点。Shiori 推理或整理时脉动，待机时灰色闪烁，其余情况保持常亮。
- **控制权交接。** 由人持有控制权（宿主在线且为手动模式）时，标识处于 `filled` 状态：镂空的 L 与独立像素变为蓝色，接管时逐格填满，交还时逐格退去。
- **预算格。** 运行预算条由 24 格组成。已用的格子点亮，最前端一格为橙色。它保留 `role="progressbar"` 及原有的 0–100 数值。

其他位置：

- **评测运行。** 能力页的运行评测与全部运行按钮在评测进行时显示 `<PixelMark loading />`。
- **状态像素。** 状态指示统一为方形，与标识的独立像素一致：外壳与能力的状态点、评测状态徽标、通知、会话分隔、回放轨道标记和来源标记。运行页的思考指示为带步进脉动的橙色像素。图表的序列标记保持圆形。
